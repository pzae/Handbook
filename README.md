# Handbook

Хэндбук, в котором я разбираю основы ML. Часть материалов разработана и описана мной, часть материалов заимствована из других источников. Основные мои вдохновители (и источники) - [Хэндбук Яндекса](https://education.yandex.ru/handbook/ml/article/about) и Лекции проекта ["Искусственный интеллект и наука МГУ имени М.В. Ломоносова"](https://github.com/EPC-MSU/EduNet-lectures/tree/dev-2.3). Репозиторий будет пополняться.
